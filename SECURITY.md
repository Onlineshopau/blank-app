# Security Policy

## Supported Versions
Only the latest version on the `main` branch receives security fixes.

## Reporting a Vulnerability
Please **do not** open public issues for security problems.

Report privately here:
https://github.com/Onlineshopau/blank-app/security/advisories/new

Include:
- A description of the issue and its impact
- Steps to reproduce
- Affected files or versions

## Response Times
- Acknowledgement: within 5 business days
- Status update: within 14 days
- Fix or mitigation: as soon as practical, based on severity

## Disclosure
Please allow us to release a fix before you disclose the issue publicly.
